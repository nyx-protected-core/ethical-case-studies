# Religion: free links to scriptures

This folder holds links only. No scripture text is copied here. Each religion has its own folder. Judaism is split into the Torah and the Talmud.

## Licensing and copyright

This folder contains links only and no copied text. Every text stays on its publisher's site, under that publisher's terms. Each link names the source, the publisher, and the licence or terms of use as the site states them, with a direct link to that licence or terms page. If a site states no terms, this is marked as "terms not stated." Links were chosen because they are free to read with no sign-in, no paywall, no fee and no region lock. Sources whose stated terms forbid public linking, or that require payment or an account to read, are left out.
