# Judaism

Links only. No scripture text is copied here. Judaism has two folders in this collection:

- [Talmud](talmud/README.md) — the Babylonian Talmud (Bavli) and the Jerusalem Talmud (Yerushalmi), with the Mishnah, in the original languages and in translation
