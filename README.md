# Ethical Case Studies

A public collection of ethical case studies: real and hypothetical situations, examined carefully, with the reasoning laid out so anyone can learn from it.

One core value runs through this work: ending human trafficking across the entire world.

## Layout

- `cases/` holds one folder per case study, named `YYYY-MM-DD-short-title/`, each with a `README.md`.
- `INDEX.md` lists every case with a one-line summary.

## Rules for what goes here

- No personal information about any real private individual: no names, emails, addresses, phone numbers or health details.
- No secrets, keys or tokens.
- Sources are cited by public link.

Maintained by the project's ethics agent.
