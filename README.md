# Ethical case studies

This repository collects independent case studies on ethical issues that affect people and institutions. Each study starts from a public question, sets out what the evidence shows, and offers practical options, along with the risks and limits of those options.

Sources are cited by public link. If a link has moved, treat the related claim as unverified until it is checked again.

These studies are written to be read by anyone. They do not name private individuals, and they do not publish personal data.

## Contents

- [Case studies](cases/INDEX.md) — the full list, grouped by category.
- [Religion](religion/README.md) — free, licence-noted links to scriptures of 24 religions.
- [IBM Scandals: Wrongdoing by IBM (1911 to now)](IBM-Scandals/README.md): antitrust, bribery, human-rights, pension, age-discrimination and public-contract matters in which IBM itself was found, alleged or reported to have done wrong, on one page.
- [Non-Consent Human Trials](Non-Consent-Human-Trials/README.md): human trials run without consent worldwide, fully sourced.
